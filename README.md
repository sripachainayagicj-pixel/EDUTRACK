# 🎓 EduTrack

EduTrack is a static student academic management platform designed to help students manage and track their academic activities, attendance, skills, projects, certifications, and career goals in one place.

## ✨ Features

* 📊 Student Dashboard
* 📱 QR-Based Attendance
* 📚 Academic Activity Tracking
* 🏆 Certifications Management
* 💡 Skills & Projects Tracking
* 🎯 Career Goals & Roadmap
* 📈 Progress Tracking
* 🔍 Skill Gap Analysis
* 📄 Resume Analyzer
* 💻 GitHub Profile Analysis

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* QRCode.js

## 🚀 Getting Started

Clone the repository and open `index.html` in your browser.

You can also use **VS Code Live Server** to run the application locally.

No backend or database setup is required.

## 🎯 Objective

EduTrack provides students with a simple and centralized platform to manage their academic information, track their progress, and support their career development.
